# Initial release baseline

Checked November 23, 2026. Salesforce Help identifies **Winter ’27** as the baseline. Verify the actual target org instance, Field Service package and mobile build before making compatibility or rollout decisions.

The Field Service change log lists November additions for Gantt search, filtering dispatch views by skill, finding appointments by lookup and formula fields, and extending Scheduling Console access. These are leads for targeted scheduling and permissions regression tests. Verify availability and prerequisites from the linked feature note before implementation.
